# pagina_de_login

Projeto simples de uma tela de login feita com HTML e CSS, com foco no aprendizado e prática de front-end.

✅ Funcionalidades

- Campos para email e senha
- Botões para:
  - Recuperar senha
  - Entrar
  - Registrar

💡 Objetivo

Este projeto foi criado com o objetivo de:
- Praticar a estruturação de páginas HTML
- Estilizar com CSS de forma responsiva e agradável
- Servir como base para um futuro sistema com a integração de uma API feita em Java


📁 Como rodar

1. Clone o repositório
2. Abra o `index.html` no navegador
